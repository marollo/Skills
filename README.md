## Sai cos'é una skill?
Una skill è semplicemente un documento che descrive un compito ripetitivo che vuoi far svolgere ad un agente di IA senza doverti ripetere ogni volta. Ad esempio, dopo una conversazione con Claude vuoi che ti venga creato un documento che contiene un recap semplice e snello in PDF. Ecco invece di scrivere ogni volta questo in un prompt dettagliato, lo si fa una volta sola e quando necessario viene avviato richiamato la skill utilizzando /{nomeSkill}.
Nell'esempio precedete la skill potrebbe essere chiamata digitando /recap.
